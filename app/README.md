# Site source

Astro source for the Chinese translation of *The Ultimate MoE Training Handbook*.

```bash
npm install
npm run dev       # http://localhost:4321/moe-handbook-zh/
npm run build     # app/dist
npm run build:gh  # build + fix base path + copy to ../docs
```

Content lives in `src/content/chapters/*.mdx`; interactive figures live in `public/viz`.
See the repository root `README.md` for attribution and licensing.
